在 iPhone 上用 Siri、分享菜单、操作按钮或轻点背面，直接问 Meta 的 Muse Spark

请用 iPhone 相机扫码打开本页

正在打开“快捷指令”…

添加 Muse

没反应的话，下载文件添加（Safari 地址栏左边的下载图标 → 点文件）

先准备密钥。Muse 要用 Meta Model API 的密钥才能调用，点“添加”之后，会弹出一栏让你粘贴。密钥在 dev.meta.ai/api-keys 创建。Meta 目前只对美国开发者开放公开预览，按 token 收费；能不能注册要看你的地区和付款方式，请先确认。

添加时

  1. 点“添加 Muse”，在弹出的栏里粘贴密钥，再点“添加快捷指令”。
  2. 第一次运行时，允许它连接 api.meta.ai，选“始终允许”。

怎么用

  • Siri：说“Muse”，听到提示后说出问题。
  • 分享菜单：选中一段文字 → 分享 → 选“Muse”，把选中的文字作为问题。
  • 操作按钮 / 轻点背面：设置里把它绑定到“Muse”。
  • 主屏幕：快捷指令里点它 → 分享 → 添加到主屏幕。

每次提问都是独立的，不带上一次的对话。回答用简体中文，尽量简短。

只连接 api.meta.ai，你的问题不经过其他服务器；密钥保存在你自己手机的快捷指令里
