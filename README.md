# 抖音无水印 · iOS 快捷指令

复制抖音分享链接，一键把无水印视频存进相册。适配 iOS 27。

**当前版本：V04（2026-10-04）**

## 添加

用 iPhone 的 Safari 打开 https://naijihzy812-blip.github.io/douyin-shortcut/ ，页面会跳转到“快捷指令”，点“添加快捷指令”。没跳转的话，点页面上的“下载文件添加”。

更新到新版本时，先在快捷指令 App 里删掉旧的“抖音无水印”，再从上面的网址重新添加。

## 使用

1. 在抖音里点 分享 → 复制链接。
2. 运行“抖音无水印”，或者在分享菜单里直接选它。
3. 第一次运行时，弹出的权限提示都选“始终允许”，访问照片选“允许”。

支持分享口令里的短链、抖音网页版视频链接、精选页链接。作品已删除或设为私密时会提示，不会存错。
